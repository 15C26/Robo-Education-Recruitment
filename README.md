# Robo-Education-Recruitment
机协纳新题，包括内训选题和授课幻灯片  

使用功能：创建仓库、建立分支、浏览分支、上传文件、修改版本、浏览历史、进行编辑处理  

遇到问题：第一次用GitHub，机器翻译不准等原因找不到按钮；网速极慢多次卡掉线；  

解决方法：禁用浏览器翻译，对着英文仔细看；搜索并使用加速器   

如何组织文件与修改流程：先由部长给成员分配自由时间段，避免多人同时操作；发现问题，维护仓库后留存记录，向上级报备；特殊情况经组织讨论后特别处理。  

使用了AI工具。将AI用作浏览器功能，大量搜索不会的资料比如GitHub用法、markdown格式等等。让AI搜索题目可能需要的资料但要求它不要生成所需答案，我再学习这些资料后自己完成题目。内训选题、幻灯片制作中，我先想好主题以及大概分支细节，让AI给我框架方案，让AI搜索资料，我经过内容数据搜索核实后，将资料整合制作PPT。并把AI所给的难度太深和低质量的内容去除，重新自己搜索资料进行补充，选取适合的图片、视频加入到幻灯片中。
